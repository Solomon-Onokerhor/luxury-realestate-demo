# Luxury Real Estate Landing Page

A hyper-premium, single-property real estate landing page built to demonstrate modern web aesthetics and high-end digital marketing for luxury real estate developers in Ghana and beyond.

## 🌟 Key Features
- **Cinematic Scroll Experience:** Video scrubbing tied to the user's scroll position for an immersive "walkthrough" feel.
- **GSAP Animations:** Smooth, high-performance text reveals and section transitions using GSAP and ScrollTrigger.
- **Dynamic Typography:** Auto-scaling, full-width typography that mimics luxury editorial magazines (Awwwards-style design).
- **Custom Preloader:** A sleek, branded loading screen that builds anticipation before revealing the property.
- **Responsive Design:** Completely fluid CSS layout (`clamp()` and `vw`/`vh` units) ensuring it looks flawless on 4k monitors and mobile devices alike.

## 🛠 Tech Stack
This project intentionally avoids heavy frameworks to maximize performance and load speed:
- **HTML5** for semantic structure
- **Vanilla CSS3** (No Tailwind) using modern CSS variables, Grid, Flexbox, and `clamp()`
- **Vanilla JavaScript** for core logic
- **GSAP & ScrollTrigger** for all high-end scroll animations

## 🎯 Purpose
Created by **Solomon Onokerhor (The Real Estate AI Guy)** as a showcase of what a top-tier digital presence should look like for real estate developers who want to target diaspora buyers and high-net-worth investors.

## 🚀 How to Run Locally
Because this project uses vanilla web technologies, there is no build step required.
1. Clone the repository: `git clone https://github.com/Solomon-Onokerhor/luxury-realestate-demo.git`
2. Open `index.html` in any modern web browser.
*(For the best experience with local video scrubbing, run it via a local server like VS Code's Live Server).*
